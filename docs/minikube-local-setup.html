Formal Document: Local Setup for Minikube Kubernetes (K8s) on macOS (Apple Silicon)

1. Prerequisites

  • Docker Desktop
    Download and install Docker Desktop for Mac:
    https://docs.docker.com/desktop/setup/install/mac-install/

2. Download and Install Minikube

  1. Download the Minikube binary for Apple Silicon (arm64):
    curl -LO https://github.com/kubernetes/minikube/releases/latest/download/minikube-darwin-arm64
  2. Install Minikube to /usr/local/bin:
    sudo install minikube-darwin-arm64 /usr/local/bin/minikube

3. Start Minikube

Start the Minikube cluster using Docker as the driver:

minikube start
  • Minikube will automatically select the Docker driver.
  • The Kubernetes control plane and related services will be started.
  • kubectl will be configured to use the minikube cluster.

4. Verify Installations

  • Check Docker version:
    docker --version
  • Check Minikube status:
    minikube status
  • Check kubectl version:
    kubectl version
  • List Kubernetes nodes:
    kubectl get nodes
  • List running Docker containers:
    docker ps
  • List Kubernetes pods (should be empty initially):
    kubectl get pods

5. Access Kubernetes Dashboard

Enable and launch the Kubernetes dashboard:

minikube dashboard
  • The dashboard will open in your default browser.
  • For full dashboard features, enable the metrics-server addon:
    minikube addons enable metrics-server

6. Notes

  • Ensure all commands are executed in the terminal.
  • Use the correct binary for your architecture (arm64 for Apple Silicon).
  • If you encounter issues with missing drivers, ensure Docker Desktop is installed and running.
Summary:
This document outlines the step-by-step process to set up Minikube and Kubernetes locally on macOS (Apple Silicon) using Docker Desktop as the container driver. The setup includes verification steps and instructions to access the Kubernetes dashboard.
